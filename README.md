# Student Management System

**Author:** Sahil Raj  
**Reg No:** 24BCY10092  
**Course:** Programming in Java  

## Description
The Student Management & Grade Tracking System is a terminal-based Java application built to manage student records, course enrollments, and academic performance. Designed for command-line execution, it runs entirely in standard terminal environments using native Java.

## Key Features
- Student Management (Add, update, search, delete)
- Grade & GPA Calculation
- Data Persistence via Java File I/O
- Interactive Command-Line Menu

## How to Run
1. Clone the repository:
   git clone https://github.com/your-username/Student-Management-System.git
2. Navigate into the directory:
   cd Student-Management-System
3. Compile the Java files:
   javac -d bin src/com/studentapp/*.java
4. Run the application:
   java -cp bin com.studentapp.Main
